# SEO Rank Tracker v2

Rediseño con enfoque editorial y animado del proyecto SEO Rank Tracker.
Cliente en React + Vite + Tailwind + Motion. Servidor en Node + Express + MongoDB.

## Estructura

- `client/` — aplicación web
- `server/` — API REST, scraping y cron

## Desarrollo

```bash
cd server && cp .env.example .env && npm install && npm run server
cd client && cp .env.example .env && npm install && npm run dev
```
